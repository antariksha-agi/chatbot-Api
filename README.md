# chatbot-Api

A beginner backend project built using FastAPI and SQLite.

## Features

* Store user messages
* Generate bot replies
* Save chat history
* Store timestamps
* Retrieve previous chats
* Delete chat records

## Technologies Used

* Python
* FastAPI
* SQLite
* Pydantic

## Project Workflow

User Message → FastAPI Route → Bot Logic → SQLite Database → Response

## Future Improvements

* Smarter bot responses
* AI model integration
* User authentication
* Search chat history
* Deployment to cloud

## Learning Goals

This project was built to learn backend development, APIs, databases, and system design fundamentals.
