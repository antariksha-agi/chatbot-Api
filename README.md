# chatbot-Api

A beginner backend project built using FastAPI and SQLite.

## Features

* Store user messages
* Generate bot replies
* Save chat history
* Store timestamps
* Retrieve previous chats
* Delete chat records
*  AI model integration
*  Smarter bot responses

## Technologies Used

* Python
* FastAPI
* SQLite
* Pydantic
* groq API
* llm model llama3

## Project Workflow

User Message → FastAPI Route → llm process → SQLite Database → Response

## Future Improvements

* User authentication
* Search chat history
* Deployment to cloud

## Learning Goals

This project was built to learn backend development, APIs, databases, and system design fundamentals.
